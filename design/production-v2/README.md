Kullanıcının 14 Kasım tarihli referansı üzerinden built-in Imagegen ile yeniden çıkarım yapıldı. Alt gövde daha dolgun, üst omuzlar daha dardır. Önceki sürüm korunur; bu sürüm kullanıcı onayı bekler. Uygulama kodu değiştirilmedi.
