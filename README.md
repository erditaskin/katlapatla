# Katla Patla

Yeni, bağımsız su balonu eşleştirme oyunu. Ultimatum kaynakları ve kayıtları bu projeye taşınmaz.

Bu aşama ürün ve görsel tasarım çalışmasıdır. Güncel yön antik Mısır ağırlıklı, karanlık ve premium metalik su balonlarıdır. React Native uygulaması henüz başlatılmamıştır.
